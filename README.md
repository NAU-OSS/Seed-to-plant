\# Seed-to-Plant



Seed-to-Plant is an educational website designed to help students learn the basic science of plant growth. The website introduces the journey from seed to mature plant and explains important ideas such as germination, photosynthesis, plant needs, plant parts, and key vocabulary.



The project was originally created as part of an educational research activity using Code.org Web Lab. The initial website was designed as a classroom-friendly learning resource. This repository adapts that work into an open source project so that educators, students, and developers can use it, improve it, and contribute new ideas.



\## Purpose of the Project



Plant growth is a common topic in elementary and middle school science, but students may encounter unfamiliar scientific terms and processes when they first learn about it.



Seed-to-Plant presents the topic in a simple, visual, and organized format. The goal is to make introductory plant science easier to explore while keeping the website lightweight and easy to use.



The project is also intended to be approachable for new open source contributors. Because it is built with basic web technologies, contributors can work on educational content, accessibility, visual design, documentation, or new learning activities without needing a complex development environment.



\## What the Website Covers



Seed-to-Plant currently includes:



\- The major stages of the plant life cycle

\- Germination and early plant growth

\- The resources plants need, including sunlight, water, air, and nutrients

\- The functions of roots, stems, and leaves

\- Important plant vocabulary

\- A visual representation of the journey from seed to mature plant

\- Interactive vocabulary sections that allow learners to reveal definitions
